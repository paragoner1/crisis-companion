# Solana SOS Functionality Guide

## Overview for Everyone
Solana SOS is your personal emergency companion. Say "Hey SOS" for instant help in crises— it guides you, calls 911, alerts contacts, and uses AI for smart advice. Works offline, rewards preparedness with tokens.

## For Professionals (First Responders/Medical)
Detailed protocols with AI enhancements for accurate triage. Integrate with 911 for seamless handoff; customizable for training levels.

## Technical Deep Dive (Developers)
- **Voice Flow**: Audio → Whisper transcription → AI analysis → Guidance.
- **AI Integration**: MobileBERT clusters symptoms; T5 generates summaries.
- Use cases with code examples.
